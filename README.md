# MaunyaJastip - Landing Page (Mobile-First)

Landing page responsif berbasis *mobile-first* untuk layanan jasa titip (Jastip) belanja produk internasional dan domestik terpercaya. Website ini dirancang agar ringan, informatif, dan langsung mengarahkan calon *customer* ke saluran komunikasi utama (WhatsApp & Instagram).

---

## 📌 Fitur Utama

* **Desain Mobile-First & Responsif**: Dioptimalkan khusus untuk pengguna *smartphone* dengan batasan area `.mobile-wrapper` (Max 480px) agar menyerupai aplikasi web *native*.
* **Navigasi Intuitif**: Navigasi *smooth-scrolling* antar bagian (Beranda, Layanan, Cara Kerja, Testimoni, Kontak).
* **Informasi Layanan Terstruktur**: Pembagian kategori jastip yang jelas (Fashion, Skincare, Gadget, Snack, Custom Request).
* **Call to Action (CTA) Terintegrasi**: Tautan langsung yang membuka aplikasi WhatsApp, profil Instagram, dan email otomatis.
